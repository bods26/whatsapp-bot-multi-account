# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-01-15

### Added
- Initial release of WhatsApp Bot Multi-Account
- Telegram Dashboard for account management
- Multi-account support
- AI chat integration (AI & GPT)
- Media conversion tools (Sticker, Quote, Emojimix, Brat)
- Downloader features (YouTube, TikTok, Instagram, Facebook)
- Mini games (Blackjack, Hangman, Slot, Tebak, Snake, Mines)
- Full RPG system with monsters and leveling
- Group management tools (Anti-link, Kick, Promote, Demote)
- Utility tools (RemoveBG, Screenshot, Sitecheck, Fetchurl)
- Search features (GitHub, YouTube Music, Waifu, Charinfo)
- REST API for external integration
- CLI commands for database management
- Rate limiting and security features
- Comprehensive documentation
- Docker support
- PM2 configuration
